# Security policy

Report vulnerabilities through GitHub private vulnerability reporting once the repository exists and the owner enables it. Until then, contact the maintainer privately through an existing channel. Include the affected version, a synthetic reproducer and the possible impact. Keep credentials, personal Garmin data and exploit details out of public issues.

For a suspected credential exposure, revoke the affected key or token and notify the maintainer privately. Treat uploaded FIT data, archives and third-party connector packages as untrusted inputs. The application is intended to run locally under the owner's account.
